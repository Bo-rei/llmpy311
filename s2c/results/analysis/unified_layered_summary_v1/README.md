# 分层汇总

该目录只合并可追溯的轻量统计，不把 current protocol、MOGB fair component、external compatibility 和 fulltex 历史 Cascade 混成一个公平排名。

- `current_protocol`：protocol_v2_textoir_v1 下的 Trainable/Frozen/MOGB fair rows。
- `external_compatibility`：ADB、DA-ADB、BRAK、MOGB strict、DCLOOS reduced 等兼容性行，表示、监督或 seed 合同不同。
- `fulltex.tex` 历史 Cascade 不在 CSV 中，需参见 `docs/analysis/MINILM_TRAINABLE_VS_FULLTEX_AND_BASELINES_V1.md`。
