## 6. Gate decoder-only 方案

- 让 LLM verifier 不只输出 yes/no，而是对候选 intent 逐个计算 next-token 似然。
- 对 uncertain 样本，先由 prototype matcher 产生 top-k 候选 intent，再用 decoder-only likelihood 进行重排序。
- 把 prototype 分数和 LLM 似然分数做显式融合，保留 `prototype / llm_verifier / fusion` 三种模式。
- 对已知意图和未知意图的边界样本，优先使用更细粒度的候选集，而不是单一阈值判定。
- 若要进一步强化分离度，可让 verifier 输出：
  - 候选 intent ranking
  - ID / OOS 分数
  - 置信区间或 margin

### 推荐落地顺序

1. 保持现有几何 gate 不变。
2. 把 semantic verifier 的输入从“yes/no 判断”扩展为“候选 intent 评分”。
3. 在 uncertain 区间里用 verifier 重排 top-k intent。
4. 再根据重排结果决定是否放行、是否判 OOS。
5. 最后再调融合权重，而不是先改主门控逻辑。
