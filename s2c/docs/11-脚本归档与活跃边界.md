# 脚本归档与活跃边界

## 1. 活跃脚本

- `scripts/data/active/`：当前仍会复用的数据构建、审计、重构脚本。
- `tools/analysis/`：当前仍会复用的分析、消融、校准入口。
- `tools/eval/`：当前仍会复用的评估入口。

## 2. 归档脚本

- 当前工作树没有 `scripts/archive/` 或 `tools/archive/`。历史复现实验的来源记录位于 `docs/historical_repro_bundle/` 和输出目录中的 manifest。
- 未来归档时，先在本文档记录“为什么归档、替代入口是什么”，再建立实际归档目录；不要在文档中预先声明不存在的路径。

## 3. 收敛规则

- 只要还在被当前文档/流程引用，就不要直接删除或移动。
- 归档前先补一条“为什么归档、替代入口是什么”。
- 归档脚本若要恢复，先补回归记录，再恢复到活跃区。
