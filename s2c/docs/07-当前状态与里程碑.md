# 当前状态与里程碑

## 1. 当前状态

- 数据层: `data/current` 已指向 `v19`，这是当前唯一的活跃版本入口。
- Gate: 训练与评估链路可用，且已经形成多个可比较的 gate 变体。
- Router: 已有稳定产物，整体准确率高于 95%，是已验证模块。
- Expert: 10 个 domain 的专家模型已经形成，平均测试准确率约 93.6%。
- Pipeline: 端到端评估已跑通，具备可用的系统级指标。

## 2. 当前真正的瓶颈

- 系统瓶颈主要在 Gate 与后段串联的边界处理，不是 Expert 本体。
- OOS 拒识与已知召回之间仍存在明显 trade-off。
- 某些 gate scoring 或 decision policy 在特定配置下会出现极端失效，需要严格约束。

## 3. 已完成里程碑

1. 统一数据协议并完成版本锁定。
2. 完成 Gate 多轮策略演进与分布诊断。
3. 打通 Gate -> Router -> Expert 系统评估。
4. 形成结构化 outputs 治理和归档规范。
5. 得到可作为主锚点的系统级 baseline。

## 4. 当前结论可以怎么概括

- 这个项目已经不是“是否可跑”的阶段，而是“如何证明哪个策略更值得保留”的阶段。
- Router 和 Expert 的单点能力都已经足够说明问题，后续消融的重点应该放在 Gate 和级联决策。
- 最合理的后续工作不是重写整个系统，而是做高质量、可复现的针对性消融。

## 5. 下一阶段重点

1. 固化 prototype 锚点基线并持续回归。
2. 把错误分解、校准指标和延迟指标纳入默认报告。
3. 推进论文口径结果包，确保结论可复现、可审计、可追溯。
4. 先做一轮聚焦 Gate 的合理消融，而不是继续扩散到无关改动。
