## 3. 当前最可靠的科学结论

1. near-OOS 主要表现为 Known 语义支持区域内部的表示碰撞，单纯扩展 K 或半径的边际收益有限。
2. CE/SupCon 往往改善 K=1，但不保证 K=2；因此“多簇普遍有效”不能作为结论。
3. StackOverflow 的 K>1 退化跨 Frozen、CE、SupCon 出现，说明固定 KMeans 多球与该数据的支持结构不匹配。
4. Gate-only 的差异可以传到完整系统，但后段 Router/Expert 和训练预算会显著改变最终结果。
5. 外部 hard-negative 的结论不是单向的：CE-Recon 在 CLINC150 改善，在 BANKING77-OOS 的 K=1 hard-negative F1 低于 Frozen。

## 4. 代表性 Cascade 的证据边界

当前代表性结果范围：

~~~
dataset ∈ {CLINC150, BANKING77-OOS, StackOverflow}
KIR = 50
data_seed = 42
Gate ∈ {
    Frozen K=1,
    Frozen validation-selected K,
    CE-Recon validation-best K,
    validation-best controlled baseline
}
~~~

共 12 个单元，四种 Gate 共用同一数据集下的 Router/Expert。

不能从这 12 个单元推出：

- 三个 seed 的系统稳定性；
- KIR25/KIR75 的系统稳定性；
- Banking77-OOS 和 StackOverflow 完整训练预算下的最终排名；
- CE-Recon 在所有下游模型上的普遍提升。
