# 工具入口索引

## 1. 主入口

- `tools/analysis/run_multi_dataset_training_v19.py`：多数据集多KIR训练主入口（支持 `--resume` 与分阶段补跑）。
- `tools/eval/eval_system_pipeline_v19.py`：系统级评估主入口。
- `tools/analysis/run_structure_backbone_ablation_v19.py`：主消融入口。
- `tools/analysis/validate_router_confidence_threshold_v19.py`：Router 阈值校准入口。
- `tools/analysis/run_prototype_gate_frozen_baseline_v19.py`：历史 prototype 最佳结果冻结复现入口。
- `tools/analysis/validate_historical_best_chain_v19.py`：历史最佳链路的来源与路径核验入口。

## 2. 辅助分析

- `tools/analysis/summarize_ablation_results_v19.py`：主消融结果汇总。
- `tools/analysis/export_ablation_table_v19.py`：论文表格导出。
- `tools/analysis/s2c_code_inventory_v19.py`：源码职责与生命周期盘点。

## 3. 已归档入口

- 历史入口不在当前推荐清单中。需要复现实验时，先从对应输出的 manifest 或 `docs/historical_repro_bundle/` 追溯，而不是猜测归档脚本路径。

## 3. 脚本治理提示

- 新增入口优先放 `tools/analysis/` 或 `tools/eval/`。
- 历史版本不能与主入口混用；新增归档前先记录可追溯的来源和用途。
- 若入口开始承担多个实验形态，应拆成 wrapper + 单一职责子脚本。
- 多数据集训练请统一使用 `dataset_slug` 目录输出（`clinc150`/`banking77_oos`/`snips`），避免混用历史大写命名目录。
