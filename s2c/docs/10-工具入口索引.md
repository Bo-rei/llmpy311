# 工具入口索引

本文件只列“当前应该从哪里进入”。不要根据文件名自行拼接参数，也不要在 main 上调用研究分支才有的命令。

## 1. main 分支：基础可运行入口

| 入口 | 用途 | 主要产物 |
| --- | --- | --- |
| python -m src.cli prepare | 准备/审计 v19 split | ../assets/datasets/s2c/prepared/ |
| python -m src.cli train | 训练多数据集主模型 | ../artifacts/s2c/outputs/experiments/multi_dataset_v19/ |
| python -m src.cli evaluate | 运行主 benchmark | ../artifacts/s2c/outputs/experiments/multi_dataset_v19/ |
| python -m src.cli ablate | 运行已登记主消融 | 由 configs/artifacts.yaml 决定 |
| tools/analysis/run_multi_dataset_training_v19.py | 多数据集训练实现 | multi_dataset_v19 |
| tools/analysis/run_multi_dataset_benchmark_v19.py | 多数据集评估实现 | multi_dataset_v19 |
| tools/analysis/run_structure_backbone_ablation_v19.py | 结构/主干消融 | 对应 ablation artifact |
| tools/eval/eval_system_pipeline_v19.py | Gate → Router → Expert 评估 | system pipeline 结果 |
| tools/analysis/validate_router_confidence_threshold_v19.py | Router 置信度校准 | 校准报告 |

先查看帮助：

~~~
python -m src.cli --help
python -m tools.experiments.cluster_separability --help
~~~

第一次运行建议只用 dry-run：

~~~
python -m src.cli prepare --dataset clinc150 --kir 50 --seed 42 --dry-run
~~~

## 2. main 分支：v19/v20/v21 研究入口

统一入口：

~~~
python -m tools.experiments.cluster_separability <command> --help
~~~

| command | 回答的问题 | 当前输出根目录 |
| --- | --- | --- |
| grid | KIR × K_gate × distance 的主网格 | cluster_separability_v19/ |
| baseline | 统一 MiniLM 表征上的 Gate-only Baseline | cluster_separability_v19/ |
| analyze | 稳定性、near/far、overlap、表示分析 | cluster_separability_v19/ |
| export | 论文表格和完整性审计 | cluster_separability_v19/ |
| v20-analysis | K 选择、near-OOS、效率汇总 | cluster_separability_v20/ |
| v20-random | KMeans 与随机分簇对照 | cluster_separability_v20/ |
| v20-end-to-end | 端到端替换实验的 preflight/命令 | cluster_separability_v20/ |
| v20-adaptive | 同表征自适应局部边界 Baseline | cluster_separability_v20/ |
| v21-semantic-probe | MiniLM 邻域、几何和 near-OOS 诊断 | cluster_separability_v21/ |
| v21-casebook | 子簇代表句和关键词审计模板 | cluster_separability_v21/ |
| v21-adaptation | Frozen/CE/SupCon 表示对照 | cluster_separability_v21/ |

这些命令在 main 的统一 CLI 中注册；参数以具体 command 的 help 为准。

~~~

~~~

## 5. 入口选择决策树

~~~
我要运行基础流程？
  └─ src.cli prepare/train/evaluate/ablate

我要补 v19/v20/v21 Gate-only 研究？
  └─ tools.experiments.cluster_separability

我要运行 v22/收口工具？
  └─ 先切 autoresearch/minilm-collision-20260718

我只想查看已有数字？

~~~

## 6. 入口治理

- 新入口必须注册到统一 CLI 或明确放在 analysis/eval 的单一职责目录；
- 历史脚本不因文件名被删除，先通过 manifest 记录来源和用途；
- 不建立新的 v24/v25 Markdown 或命令入口；
- 任何“结果可读但源码不可复现”的情况都要在文档中明确注明。
